### \# Hierarchical Multi-Label Text Classification



#### \*\*Final Project for DATA304: Big Data Analysis\*\*



###### A zero-shot hierarchical multi-label classification project for Amazon product reviews.

###### The final pipeline combines SBERT-based semantic retrieval with DAG-based True Path Rule post-processing to preserve parent-child consistency in predictions.

###### **Final Example-F1: ~0.47** &nbsp; | &nbsp; Raw SBERT baseline: ~0.15



##### 

##### 📂 Project Structure



\- `sbert.py`: Main executable script containing data loading, semantic embedding, prediction, and hierarchy-aware post-processing.

\- `classes.txt`: Class IDs and category names used in the taxonomy.

\- `class_hierarchy.txt`: Parent-child relationships defining the hierarchical taxonomy.

\- `class_related_keywords.txt`: Related keywords used to enrich each class representation.

\- `test_corpus.txt`: Input corpus used for inference.

\- `requirements.txt`: List of Python dependencies.

\- `submission.csv`: Final prediction results generated by the pipeline.



##### 🛠 Prerequisites



\- Python 3.10+ recommended

\- PyTorch

\- CUDA is optional. The script automatically uses GPU when available and otherwise runs on CPU.

##### 🧠 Method



###### 1\. Semantic Retrieval

&nbsp;    Model: The pipeline uses the pre-trained `all-MiniLM-L6-v2` model from Sentence-Transformers.

&nbsp;    Class Representation: Each class name is combined with its related keywords from `class_related_keywords.txt` and embedded into a shared vector space.

&nbsp;    Review Representation: The product name and review text are embedded into the same vector space.

&nbsp;    Similarity: Cosine similarity between each review embedding and the class embeddings is used to rank candidate categories.



###### 2\. Hierarchy-Aware Post-Processing

The class taxonomy is represented as a Directed Acyclic Graph (DAG), and the True Path Rule is applied to preserve hierarchical consistency.

&nbsp;  1. Candidate classes are considered in descending order of cosine similarity.

&nbsp;  2. When a candidate class is selected, all of its ancestor nodes are added to the prediction set.

&nbsp;  3. Candidates are added until the prediction set contains at least 3 labels.

&nbsp;  4. If more than 3 labels are present, low-scoring leaf nodes are iteratively removed until 3 labels remain.



##### 📈 Result



###### Raw SBERT retrieval: **Example-F1 ~0.15**

###### SBERT + DAG-based True Path Rule: **Example-F1 ~0.47**



##### 📝 Reproducibility



To improve reproducibility, random seeds for Python, NumPy, and PyTorch are fixed to 42 at the beginning of execution.
